# 오늘의 감사 — 사용 안내

마음을 돌보는 짧은 감사 기록 앱입니다. 아래 순서대로 하면 아이폰 홈화면에 아이콘을 추가하고, 시리로도 열 수 있습니다.

## 1. GitHub Pages로 올리기

1. GitHub에서 새 저장소(Repository)를 만듭니다. (예: `gratitude-journal`)
2. 이 폴더 안의 파일 전부를 저장소에 업로드합니다.
   - `index.html`
   - `manifest.json`
   - `service-worker.js`
   - `icons/` 폴더 (아이콘 3개)
3. 저장소 **Settings → Pages** 로 이동합니다.
4. **Source**를 `Deploy from a branch` → `main` / `(root)` 로 설정하고 저장합니다.
5. 몇 분 뒤 아래와 같은 주소가 생깁니다.
   ```
   https://내아이디.github.io/gratitude-journal/
   ```
   이 주소가 이제 나만의 감사 기록 앱 주소입니다.

## 2. 아이폰 홈화면에 추가하기

1. 아이폰 **Safari**에서 위 주소로 접속합니다. (다른 브라우저는 홈화면 추가가 안 될 수 있어요)
2. 하단 **공유 버튼**(네모에 화살표) 터치
3. **홈 화면에 추가** 선택
4. 이름을 "오늘의 감사"로 두고 **추가**
5. 홈화면에 아이콘이 생기고, 앱처럼 전체화면으로 열립니다.

## 3. 시리(Siri)로 열기

1. 아이폰 **단축어(Shortcuts)** 앱을 엽니다.
2. 우측 상단 **+** 를 눌러 새 단축어 생성
3. **동작 추가** → "URL 열기" (Open URLs) 검색해서 추가
4. URL 칸에 위 GitHub Pages 주소를 붙여넣기
5. 단축어 이름을 "감사 기록" 처럼 정하고, 오른쪽 (i) 아이콘 → **Siri에 추가**에서 원하는 음성 문구를 녹음
6. 이제 "시리야, 감사 기록 열어줘" 라고 말하면 바로 앱이 열립니다.

## 4. 기록은 어디에 저장되나요?

- 기록은 이 기기(아이폰)의 **Safari 브라우저 안**에 저장됩니다. (localStorage)
- 앱을 지우거나 브라우저 데이터를 지우면 기록도 함께 사라질 수 있어요.
- 그래서 화면 안의 **"전체 내보내기"** 버튼을 가끔 눌러주세요.
  - 모든 기록이 텍스트로 복사되고, 동시에 `.txt` 파일로도 저장됩니다.
  - 이 텍스트를 그대로 워드/메모/한글 문서에 붙여넣으면 영구 보관이 가능합니다.
- 기록 하나하나 옆의 **"문서용 복사"** 버튼으로 그날의 기록만 따로 복사할 수도 있어요.

## 5. 더 오래, 더 안전하게 남기고 싶다면

- 한 달에 한 번 정도 "전체 내보내기"로 백업해서 본인 이메일이나 클라우드(아이클라우드, 구글드라이브 등)에 보관하시길 추천드립니다.
- 나중에 더 안정적으로 만들고 싶다면 Firebase나 Google Sheets 같은 곳에 자동 저장되도록 확장할 수도 있어요. (원하시면 다음 단계로 도와드릴게요)
