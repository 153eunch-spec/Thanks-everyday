기록된 시트를 빠르게 열어볼 수 있는 링크예요. 몰라도 괜찮아요.

구글시트 연동 방법 보기
  1. 구글시트(sheets.google.com)에서 새 스프레드시트 생성
  2. 상단 메뉴 확장 프로그램 → Apps Script 클릭
  3. 기본 코드를 지우고, README에 있는 코드를 붙여넣기
  4. 저장 후 배포 → 새 배포 클릭
  5. 유형: 웹 앱 선택 / 액세스 권한: 전체 선택 후 배포
  6. 나오는 웹앱 URL을 위 칸에 붙여넣고 저장
